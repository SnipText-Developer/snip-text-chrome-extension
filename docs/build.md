# 환경 설정 및 빌드

## 대시보드 빌드

Node.js 20 이상과 npm이 설치된 환경에서 프로젝트 루트로 이동합니다.

1. 환경 변수 예제 파일을 `.env.local`로 복사합니다. `.env.local`이 이미 있으면 기존 파일을 열어 설정을 확인합니다.

   ```sh
   cp -n .env.example .env.local
   ```

2. 의존성을 설치하고 운영용 번들을 생성합니다.

   ```sh
   npm install
   npm run build
   ```

   빌드 결과는 `build/`에 생성됩니다. `.env.local` 값을 변경하면 다시 빌드해야 반영됩니다.

## Chrome 확장 프로그램 압축 및 ID 고정

1. **확장 프로그램 압축 열기**
   Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켠 뒤 **확장 프로그램 압축**을 누릅니다.
2. **빌드 폴더 선택 및 PEM 파일 지정**
   **확장 프로그램 루트 디렉터리**에 `manifest.json`이 있는 확장 프로그램 빌드 폴더를 선택합니다. **비공개 키 파일**에 별도로 제공받은 `.pem` 파일을 선택한 뒤 **확장 프로그램 압축**을 누릅니다.
3. **기존 확장 프로그램 ID 유지**
   다시 압축할 때도 **같은 PEM 파일**을 지정해야 기존 ID가 유지됩니다. 비공개 키 파일을 비워 두면 Chrome이 새 키를 생성해 ID가 달라집니다.

PEM 파일은 별도로 보관하고 Git 저장소나 배포 파일에 포함하지 않습니다.
